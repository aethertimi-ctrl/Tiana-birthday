Put the photos for the page in this folder.

  portrait.jpg   -> the hero photo at the very top of the page
  1.jpg, 2.jpg … -> the gallery (shown in filename order, tap to enlarge)

Supported: jpg, jpeg, png, webp, avif. (iPhone .HEIC files must be converted
to .jpg first, browsers can't show them.) About 1600px wide is plenty.

Captions: open src/data/gallery.ts and edit `captions`. The key is the file
name without its extension, so 3.jpg is '3'.

No list to maintain: add a file and it appears, delete it and it's gone.
